# ToolDeck 应用使用说明

[English](user-guide.md) | 简体中文 · [项目介绍](../README.zh-CN.md)

## 导入并运行第一个工具

1. 点击左侧面板底部的**导入工具**，或将一个 ZIP 拖到左侧面板。核对弹窗中的工具信息，确认导入。想先体验示例，可以按[项目介绍中的步骤](../README.zh-CN.md#从源码启动)生成示例 ZIP。
2. 选中工具，打开**环境**，查看支持的平台、宿主 API、运行时版本和依赖要求。
3. 如果工具需要准备环境，点击**安装**。每个 Python 工具都有独立的 `.venv`，uv 会选择版本匹配的本机 Python，仅在工具声明依赖时安装第三方包。声明了依赖的 Node.js 工具使用 npm 安装。Bash 和 PowerShell 工具使用系统中的 Shell。
4. 打开**文档**阅读工具说明。如果有**工具设置**页，在其中填写需要重复使用的配置，例如可执行文件路径，然后保存。
5. 进入**操作**页，选择操作并填写参数。多选文件字段可以追加文件、逐个移除。修改选项时可能会出现新的必填字段。如果工具要求输出路径，选择保存位置，然后点击**运行**。
6. 在结果区查看进度和日志。有些工具还会输出表格、文件或目录链接。运行期间可点击**停止运行**；中断后能否续跑，取决于工具自身的设计，具体见该工具的说明。

可在侧栏搜索已导入的工具。点击工具标题旁的星标，即可从**收藏**分组快速找到它。

## 应用设置

从侧栏进入**应用设置**。首次启动时应用会匹配系统语言，无法匹配时使用英文。选择 English 或简体中文并保存即可切换。工具可为不同语言提供字段标签、文档和脚本输出。

Node.js 和 uv 的路径留空时会自动检测。若检测失败，可以手动选择可执行文件，或在安装后重新检测。对于 Python 工具，还需确保本机有满足**环境**页版本范围的 Python。Bash 和 PowerShell 需要在系统路径中提供 `bash` 或 `pwsh`。

## 升级、卸载与删除

| 操作 | 结果 |
| --- | --- |
| 导入相同 ID 的更高版本 | 确认升级后保留工具设置和持久数据。运行时或依赖变化时，可能需要重新安装环境。同版本和更低版本无法覆盖导入。 |
| 卸载 | 移除已安装的环境，保留脚本、设置和持久数据，以后可以重新安装。 |
| 删除 | 删除工具及其脚本和环境。“工具设置”默认勾选删除；取消勾选可保留，并在重新导入时恢复。还可勾选删除“运行数据”（会话、历史记录和缓存）及“此工具的运行日志”；未勾选的内容保留，保存在用户指定位置的文件不受影响。 |

## 查找产物与日志

**应用数据目录**下，`tools/<id>/` 存放工具文件，`data/<id>/` 存放脚本的持久数据，`logs/` 存放运行记录。修改应用数据目录会切换工具库，原有文件仍在原目录。重新选择旧目录即可切回原工具库。

生成的文件保存在执行操作时指定的位置。每次运行还有一个临时目录，任务结束后由 ToolDeck 清理。**清理运行日志**会删除保存的运行记录，保留生成的文件。

# Bash example

Choose **Preview greeting** to print the greeting, or **Save greeting** to write a new UTF-8 file. Choose an absolute destination path in an existing directory.

The scripts read the display language from `TOOLDECK_LOCALE`. Leave the prefix blank for a greeting in the selected language, or enter your own prefix. The uppercase setting applies to the resulting message. Save confirmations and validation messages also follow the display language.

The tool supports macOS and Linux. See the manifest for the required Bash version.
